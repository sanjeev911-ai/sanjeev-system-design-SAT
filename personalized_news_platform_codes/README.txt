Personalized News & Information Platform — Round 2 and Round 3 code

Files:
- round2_low_level_design.py: REST APIs for search, article details, follow topic, personalized feed, and trending news.
- round3_high_level_design.py: Simplified API examples representing news, personalized feed, and trending news.
- requirements.txt: Python dependency.

Run:
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. For Round 2: python round2_low_level_design.py
5. For Round 3: stop the first server, then run python round3_high_level_design.py

The sample data is stored in memory for demonstration; it is not a production database.
Default server address: http://127.0.0.1:5000
